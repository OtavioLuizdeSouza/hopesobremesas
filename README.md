# Hope Sobremesas

Site institucional e catálogo digital da **Hope Sobremesas**, criado para apresentar a marca, suas categorias de produtos e uma forma simples de iniciar um pedido.

## Sobre o projeto

O projeto foi desenvolvido com uma interface leve, acolhedora e responsiva. Os visitantes podem navegar pelas categorias, conhecer os produtos disponíveis, montar um carrinho e seguir para o atendimento da loja.

Este repositório contém apenas a parte visual do site. Nenhuma informação confidencial, credencial, dado de cliente ou sistema interno da empresa é armazenado aqui.

## Funcionalidades

- Apresentação da marca e de sua proposta;
- catálogo organizado por categorias;
- carrinho de produtos;
- direcionamento para o canal de atendimento;
- layout adaptado para computadores e dispositivos móveis.

## Tecnologias utilizadas

- HTML5;
- CSS3;
- JavaScript.

## Executando localmente

Faça o download ou clone este repositório e abra o arquivo `index.html` em um navegador moderno. Como o projeto utiliza apenas tecnologias da web no lado do cliente, não é necessário instalar dependências para visualizar sua interface.

## Status

O site está em desenvolvimento e pode receber ajustes visuais, novos produtos e melhorias de experiência ao longo do tempo.
