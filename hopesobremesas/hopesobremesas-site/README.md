# Fada dos Doces

Abra `index.html` no navegador para visualizar o site.

## O que editar

- Em `script.js`, troque `WHATSAPP_NUMBER` pelo número da loja, somente com números. Exemplo: `5511999999999`.
- Troque os nomes dos produtos dentro de `const products`.
- Para definir preços e fotos, use os cartões como modelo e edite `index.html`, `style.css` e `script.js` conforme necessário.
- As imagens do banner e da logo ficam em `assets/`.

O botão de finalizar abre o WhatsApp com a lista de itens. O valor foi deixado vazio de propósito para ser preenchido depois.
